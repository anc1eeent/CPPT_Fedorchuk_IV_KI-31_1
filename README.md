# CPPT_Fedorchuk_IV_KI-31_1
Лабораторні роботи з предмету "Кросплатформні засоби програмування"

## Лабораторна робота №2: Об'єктно-орієнтована обробка бази тренажерного залу (Варіант 20)

### Призначення
Програма читає записи про клієнтів тренажерного залу з файлу `data/input.csv`. На відміну від першої версії, друга лабораторна робота реалізує принципи Об'єктно-Орієнтованого Програмування (ООП). Кожен рядок перетворюється на об'єкт-сутність `Membership` із суворою валідацією інваріантів у конструкторі. Статистичні показники агрегуються та пакуються у незмінний тип `record MembershipSummary` для безпечної передачі даних перед формуванням фінального звіту. Проєкт додатково покритий модульними тестами (JUnit 5).

### Формат вхідних даних
Один запис розміщується у рядку, поля розділяються крапкою з комою (`;`). Файл має бути у кодуванні UTF-8. 
**Формат запису:** `Клієнт;Тариф;Місяці;Відвідування;Ціна`

**Приклад `data/input.csv` (з обробкою помилок):**
```csv
Іван Федорчук;Безліміт;12;45;1500.50
Петро Коваль;Ранковий;3;10;500.00
Олена Петрівна;Разовий;-1;1;150.00

### Збірка та запуск
Проєкт використовує Maven Wrapper, тому вам не потрібно встановлювати Maven глобально на ваш комп'ютер. 

**На Windows:**
```bash
.\mvnw.cmd clean verify package
```

**На Linux / macOS:**
```bash
./mvnw clean verify package
```

**Запуск:**
```bash
java -jar target/maven-actions-hello-0.1.0.jar --input data/input.csv
```
