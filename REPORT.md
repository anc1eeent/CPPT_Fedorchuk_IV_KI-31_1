# Звіт до лабораторної роботи № 3

## 1. Тема, номер і варіант
- **Тема:** Спадкування, інтерфейси й поліморфізм у Java-проєкті.
- **Предметна область:** Тренажерний зал
- **Номер варіанта:** 20
- **Операційна система:** Windows 11 (розробка), Ubuntu/macOS/Windows (CI/CD)

## 2. Мета роботи
Розширити класову модель предметної області: винести спільні властивості до базового типу, створити підтипи з різною поведінкою, додати enum для категорії, реалізувати `equals/hashCode` і обробляти різнорідні об'єкти через спільний тип[cite: 1].

## 3. Постановка задачі
Модифікувати об'єктно-орієнтований додаток обробки бази клієнтів тренажерного залу:
1. Замінити монолітний клас `Membership` на абстрактний базовий тип[cite: 1].
2. Створити підтипи `MonthlyMembership` та `AnnualMembership` з різною реалізацією розрахунку вартості відвідування[cite: 1].
3. Використати перелічуваний тип (`enum`) для фіксації категорій абонементів[cite: 1].
4. Забезпечити логічну унікальність об'єктів у колекції `HashSet` через узгоджені методи `equals` та `hashCode`[cite: 1].
5. Обробити всі об'єкти через поліморфний метод без `if` або `switch` за типом[cite: 1].

## 4. Структура програми
Програму розділено на незалежні файли (пакет `ua.lpnu.kzp`):
- **`MembershipKind.java`:** Перелічуваний тип (`enum`), що визначає категорію (MONTHLY, ANNUAL)[cite: 1].
- **`Membership.java`:** Базовий абстрактний клас, що містить спільні поля (ім'я клієнта), методи `equals/hashCode` та делегування конструктора для безпечної ініціалізації.
- **`MonthlyMembership.java` / `AnnualMembership.java`:** Класи-спадкоємці, які містять унікальні математичні поля та перевизначений поліморфний метод `visitCost()`[cite: 1].
- **`Main.java`:** Головний клас. Читає файл, використовує фабричний метод `parseCsv` для генерації підтипів, поліморфно обчислює вартість візитів та фільтрує дублікати через `HashSet`[cite: 1].

## 5. Інфраструктура
- **Система збірки:** Maven (запуск через Maven Wrapper).
- **Тестування:** JUnit 5 (додано тести поліморфної поведінки та логічної рівності в HashSet)[cite: 1].
- **Статичний аналізатор:** SpotBugs (виявлено та усунено вразливість `CT_CONSTRUCTOR_THROW` через патерн делегування конструктора).
- **Пакування:** `maven-shade-plugin` формує виконуваний JAR.
- **CI/CD:** GitHub Actions з матрицею (ubuntu-latest, windows-latest, macos-latest).

## 8. Тестування, CI і артефакти
Локальне тестування проводилось командою `.\mvnw.cmd clean verify`.
