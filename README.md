# CPPT_Fedorchuk_IV_KI-31_1
Лабораторні роботи з предмету "Кросплатформні засоби програмування"

## Лабораторна робота №1: Обробка бази тренажерного залу (Варіант 20)

### Призначення
Програма читає записи про клієнтів тренажерного залу з файлу `data/input.csv`, перевіряє їх на коректність, обчислює статистичні показники (виторг, середню кількість відвідувань, найдовший абонемент) та формує форматований звіт у консоль і текстовий файл `out/report.txt`.

### Формат вхідних даних
Один запис розміщується у рядку, поля розділяються крапкою з комою (`;`). Файл має бути у кодуванні UTF-8. 
**Формат запису:** `Клієнт;Тариф;Місяці;Відвідування;Ціна`

**Приклад `data/input.csv` (з обробкою помилок):**
```csv
Іван Федорчук;Безліміт;12;45;1500.50
Петро Коваль;Ранковий;3;10;500.00
Олена Петрівна;Разовий;помилка;1;150.00```

### Збірка та запуск
Проєкт використовує Maven Wrapper, тому вам не потрібно встановлювати Maven глобально на ваш комп'ютер. 
# На Windows:
.\mvnw.cmd clean verify package

# На Linux / macOS:
./mvnw clean verify package

# Запуск:
java -jar target/maven-actions-hello-0.1.0.jar --input data/input.csv
# Перевірка версії:
java -jar target/maven-actions-hello-0.1.0.jar --version
